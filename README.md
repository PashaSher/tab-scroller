# Tab Scroller

A simple desktop tool for automatic scrolling and tab switching.  
Useful for keeping a window "active", simulating user activity (e.g. avoiding auto-logout), UI testing, or just for fun.

## 🔧 Features

- Randomized scroll up/down behavior
- Random Ctrl+Tab / Ctrl+Shift+Tab tab switching
- Easy Start / Stop with a graphical interface
- No need to install Python on the target machine

## 🖥️ How to Use

1. Download the `.zip` file from the [Releases](https://github.com/PashaSher/tab-scroller/releases) section.
2. Extract and run the program (`TabScroller.exe`)
3. Click **Start Scrolling**
4. Switch to the application you want to automate (within 5 seconds)
5. To stop, click **Stop Scrolling**
6. To exit, click **Exit**

> ⚠️ Important: While the program is running, it will simulate keyboard and mouse events. Do not use it for malicious purposes.

## 📦 System Requirements

- Windows 10/11
- No Python installation required
